Steading

Farm records that work without a signal.

Install on this phone

There is no build on the server yet. Nothing is broken — come back when you are told there is one.

Android will ask you two things. Both are normal.

“This type of file can harm your device.” Chrome says this about every app that does not come from the Play Store. Choose Download anyway.

“Unknown developer” or “app not scanned”. That is Play Protect noticing the app is not published on the store yet. Choose Install anyway.

You may also be asked to allow installing apps from Chrome. That is asked once.

Then

  1. Open it and start using it. There is nothing to set up and no account needed. Everything you log is on the phone straight away.
  2. Make an account when you want a copy somewhere else. Settings → Keep these records safe. Until then, everything lives on this phone and nowhere else — so uninstalling the app, or clearing its data, takes it.
  3. If something goes wrong, tell it. Settings → Something is wrong. It already knows what happened and sends that; there is nothing you have to describe.

Open this page on the phone you want it on — the file is for Android and will not do anything on a computer.
