# Steading — for agents

There is no Next.js here. The block that used to sit at the top of this file was
generated by a Next.js install the project no longer has, and it pointed at
`node_modules/next/dist/docs/`, which does not exist. Anyone following it was
reading docs for a framework this app does not use.

The client is React Native (Expo SDK 57) in `apps/mobile`; the server is
Fastify in `apps/api`; the shared contract is `packages/contracts`. `CLAUDE.md`
at the root is the project's instructions and is kept accurate — read it first.
